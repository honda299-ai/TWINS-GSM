# مجلد الأدوات — TWINS GSM

هنا تضع ملفات الأدوات اللي عايز الناس تنزلها من الموقع.

## طريقة الاستبدال (سهلة جداً)

1. احذف الملفات التجريبية الموجودة هنا.
2. ضع ملفاتك الحقيقية بنفس الأسماء:

| الاسم في الموقع | اسم الملف المطلوب |
|---|---|
| TWINS FRP Helper | `twins-frp-helper.zip` |
| TWINS IMEI Fix Kit | `twins-imei-fix-kit.zip` |
| TWINS Flash Guide | `twins-flash-guide.zip` |
| TWINS CSC Changer | `twins-csc-changer.zip` |
| TWINS Boot Rescue | `twins-boot-rescue.zip` |
| TWINS Device Checker | `twins-device-checker.zip` |

3. لو حابب تغيّر الأسماء أو تضيف أدوات جديدة، عدّل قسم `tools` في ملف `data.js` في مجلد الموقع الرئيسي.

## ملاحظات مهمة

- حجم الملفات التجريبية صغير جداً؛ استبدلها قبل النشر.
- لو عايز كلمة التحميل تبقى "قريباً" بدل "تحميل"، خلي قيمة `file` تساوي `"#"`.
- يفضّل ضغط الأدوات كـ ZIP لتقليل حجم التحميل.
- راجع ملفاتك قبل رفعها على الإنترنت عمل فيروس scan.

## تحديث الديزاين (Mobile-first)

- `redesign.css`: طبقة ديزاين جديدة تُحمّل بعد `modern.css` في `index.html` و`account.html`.
- `ui-enhancements.js`: شاشة تحميل، شريط تنقل سفلي في الموبايل، وحالة "جاري التحميل" لزر التحميل.
- اللوجو الجديد المرفق اتحط في `assets/logo-mark.png` (شعار صغير شفاف) و`assets/twins-logo.png` (لوجو كامل داخل قائمة الموبايل)، والنسخة الأصلية `assets/twins-logo.webp`.
- القائمة الرئيسية اعتُدلت: أيقونات واضحة، كروت لكبير، لوجو وزر إغلاق داخل قائمة الموبايل، وتناسب مع التابلت بدون تمرير أفقي.
- زر **دخول** ظاهر في هيدر الموبايل، داخل القائمة، في الهيرو، وفي شريط التنقل السفلي.
- رابط `account.html?mode=register` يفتح مباشرة على تبويب إنشاء حساب.
- الأدوات والأسعار والتحميل ظهروا كخانات واضحة بأزرار لمس كبيرة.
- لو حابب ترجّع الديزاين القديم، احذف سطر `redesign.css` من ملفي `index.html` و`account.html` وسطر `ui-enhancements.js` من `index.html`.

## مركز التحميل وصندوق PRO (جديد)

- قسم التحميل بقى مكان مستقل (`#downloadShell`)؛ تحته تبويبان: **تحميل عادي** و**تحميل PRO**، مع بطاقة مميزة اختيارية أعلى الصفحة.
- من لوحة التحكم: `الإعدادات ← ⬇ مركز التحميل` تقدر تغيّر العناوين والنصوص، وتتحكم في ظهور كل تبويب، وتضيف **صورة + رابط + زر نسخ** للبطاقة المميزة. أي زر بيختفي تلقائياً لو خليت مجاله فاضي أو قفلت "إظهار".
- من لوحة التحكم: `محتوى PRO` تقدر تضيف لكل عنصر صورة، رابط، نص نسخ، يوزر/باسورد، وتتحكم في ظهور كل عنصر على حدة. خيار **يظهر لكل الأعضاء المسجلين** بيسمح بعناصر PRO للعضو العادي بدل ما تكون لأعضاء PRO بس.
- صندوق PRO اتبنى من جديد بشكل عصري: حالة انتظار، حالة قفل/ترقية واضحة، كروت منظّمة، وأزرار نسخ مع fallback للمتصفحات اللي مفيهاش Clipboard API.
- الحماية الحقيقية في `firestore.rules`؛ الواجهة بتقرأ العضوية من `memberships` وتعرض المحتوى المسموح حسب القواعد، مع fallback آمن لعناصر `forAll`.
