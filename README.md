# TWINS GSM — نسخة Mobile Pro

موقع TWINS GSM مع **هاتف تفاعلي كامل** يعمل على الموبايل والكمبيوتر، بدون أي بناء أو npm.

## اللي اتضاف حديثاً

- `phone-studio.css` / `phone-studio.js` — الهاتف التفاعلي.
- زر **الهاتف** في الهيدر + شريط اختصارات سفلي في الموبايل (الهاتف / جهات الاتصال / الرسائل / الأدوات / واتساب).
- الهاتف التفاعلي بيفتح بملء الشاشة على الموبايل، وداخل إطار جهاز على الكمبيوتر.

## الهاتف التفاعلي بيعمل إيه؟

- **الهاتف**: لوحة أرقام، بحث تلقائي عن جهة اتصال بالرقم، زر مكالمة تجريبية، ومحاكاة مكالمة واردة.
- **المكالمة**: بتعرض «جاري الرنّ» ثم «مكالمة متصلة» مع مؤقت، نغمة/اهتزاز اختياري، كتم، مكبر، لوحة أرقام، وإنهاء.
  أثناء المكالمة اضغط `1` أو `2` أو `3` لاختيار خدمة (صيانة / أدوات / واتساب) — الرد بيظهر داخل شاشة المكالمة.
- **جهات الاتصال**: قائمة، بحث، فلاتر (الكل / المفضلة / فريق TWINS / الخاصة بي)، إضافة وتعديل وحذف جهات، وتحويل للمفضلة.
- **السجل**: كل المكالمات التجريبية (صادرة / واردة / فائتة) مع مسح السجل.
- **الرسائل**: محادثات تجريبية مع رد تلقائي ذكي حسب كلمة البحث.
- **الإعدادات**: صوت، اهتزاز، قائمة الخيارات التلقائية، الرد التلقائي، حجم خط أكبر، 4 ألوان للواجهة، وإعادة ضبط.

## اتصال حقيقي من الموبايل

المحاكاة جوه الموقع بس. بس فيه أزرار واضحة بتفتح تطبيقات الجهاز بعد موافقتك:

- `✆ اتصال حقيقي بالجهاز` → رابط `tel:` يفتح تطبيق الهاتف بالرقم.
- `واتساب` → رابط `wa.me`.
- `رسالة SMS` → رابط `sms:`.

المتصفحات **ما تقدرش** تعمل مكالمة صامتة أو تقرأ جهات اتصال الجهاز تلقائياً؛ لازم المستخدم يوافق. ده سلوك أمني من iOS وAndroid.

## تعديل البيانات

كل حاجة من ملف `data.js`:

- `contact` — الرقم والواتساب والإيميل والسوشيال.
- `phoneContacts` — جهات الاتصال الافتراضية (بدّل الأرقام التجريبية بأرقامك).
- `phoneReplies` — نصوص الردود أثناء المكالمة والمحادثة.

جهات الاتصال والرسائل والسجل والإعدادات بتتحفظ في `localStorage` على جهاز الزائر، ومفيش أي بيانات بتتبعت لسيرفر.

## رفع الموقع

ارفع محتويات المجلد (الملفات على الـ root) على GitHub Pages / Firebase Hosting / أي استضافة ثابتة. الملف `index.html` هو الصفحة الرئيسية.
لازم تعدّل `firebase-config.js` قبل النشر لو عايز الدخول والأدمن شغالين؛ غير كده الموقع هيشتغل بالبيانات المحلية.

## ملاحظة

الأرقام في `phoneContacts` تجريبية (`+20 100 000 0000` …) — بدّلها قبل النشر.
